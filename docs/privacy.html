Privacy policy

Drive-To-Tube · Hidayah Academy for Islamic Education · last updated 10 October 2026

Drive-To-Tube is an internal tool used by Hidayah Academy for Islamic Education to publish its recorded classes. This page explains what data it touches, why, and what it does not do. See the home page for what the tool is.

1. Google accounts the tool connects to

The tool connects to two Google accounts, both belonging to the academy's administrators. It does not ask students or any other member of the public to connect a Google account.

  • Google Drive (scope https://www.googleapis.com/auth/drive): to list the class recordings and their folders, to read the recording files so they can be uploaded, and to move recordings and folders into an organised structure, and to list the academy's study-material folders (books and audio) so they can be catalogued for students. It never deletes a recording; the only things it moves to the Drive trash are empty Google Meet folders, which can be restored from the trash.
  • YouTube (scope https://www.googleapis.com/auth/youtube): to upload class recordings as unlisted videos to the academy's channel, add them to the academy's playlist, set their thumbnails, and check the channel's existing uploads to avoid duplicates.

2. What is stored, and where

  • Google access tokens are stored in a private configuration file on the administrator's own computer. They are not published, shared or sent to anyone other than Google.
  • Recording records (file names, titles, upload status and YouTube links) are stored in the academy's database so staff can review and track uploads.
  • The recordings themselves stay in the academy's Google Drive and YouTube. The tool streams a file to YouTube and keeps no permanent copy; for audio-only recordings it briefly creates a temporary video file while preparing the upload, and deletes it afterwards.

3. Student portal

Enrolled students register with an invite code from the academy. The portal stores each student's chosen username, display name, a hashed password (the password itself is never stored) and which lectures they have watched. This is used only to run the portal and to let the academy's teachers see class progress. It is not used for advertising and is not sold or shared with third parties.

4. Who else handles the data

To run the service the academy uses third-party hosts that process data on its behalf: Google (Drive and YouTube), Neon (database), Render (the student API) and Vercel (the student website). They receive only what is needed to operate the service.

5. Google API Services User Data Policy

Drive-To-Tube's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained from Google is used only to provide and improve the features described above. It is not used for advertising, not sold, and not read by humans except where needed to operate the service, for security, or to comply with law.

6. Your choices

  • Administrators can revoke the tool's access at any time at myaccount.google.com/permissions.
  • Students can ask the academy to correct or delete their portal account and progress.
